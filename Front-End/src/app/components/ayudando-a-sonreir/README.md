# Ayudando a Sonreír Component

## Overview
Static informational page detailing Dental One's community social-support initiative and linking interested patients to `/contact-us`.

## Interface
- `AyudandoASonreir` (`[ayudando-a-sonreir.ts:AyudandoASonreir]`): Standalone Angular component (`selector: 'app-ayudando-a-sonreir'`) importing `RouterLink` and rendering static template content (`[ayudando-a-sonreir.html]`).

## Invariants
- None.

## Side Effects
- None.

## Verification
- Run: `npm --prefix Front-End test`
